## Haunted Places in the U.S

This dashboard visualizes the locations of the most haunted places in the United States. 
The data set was sourced from a ghostly encounter repository online, which records reports of the haunted or unworldly encounters that people have across the nation. 
The map shows hotspots and density points of locations. 
While the bar chart shows the count per state.
